WatchDogsGo 0.9.18
Original game by LOCOSP. Modified by KiloGramowy.

KEEP YOUR EXISTING XP
Fix migration from LOCOSP's older loot database format (v1).
Saved XP, level, badges, contacts, discovery history and session counts
are preserved. Missing session logs do not erase their saved counters.
Previously saved zero XP stays zero; no duplicate XP is granted.

Before migration, keep a byte-for-byte private backup beside loot_db.json.
Repeated launches do not repeat the migration. An unsafe read or write
stops startup instead of showing an empty player. RF, scoring rates,
chat, GPS profiles and upload behavior are preserved.

BLE BRIDGE SCAN COMPLETION
Accept the Linux WiFi/BLE bridge's exact final BLE scan done marker,
alongside the existing projectZero/XIAO Summary. Save checks, the pause
and confirmed STOP handover remain in place. Adapter warnings pause the
schedule instead of counting a failed scan as a successful empty scan.
Late markers do not restart a cancelled schedule. Compatible adapters,
drivers and an already configured bridge are still required.

SEPARATE CLONE, EXISTING DATA
A new folder has its own loot directory. Launch the new run.sh with
the old installation root as its data argument to use your existing save:
./run.sh /absolute/path/to/old/WatchDogsGo
Use the installation root, not the loot folder, and close the old game.
Project-local account/plugin settings are separate from that data option.
Read docs/UPGRADING_FROM_LOCOSP.md before moving or restoring saves.

If an earlier build already overwrote the save, keep the current data
and look for an intact old copy or backup. Exact erased XP cannot be
recovered reliably by guessing from logs or the WDGWars server score.
