RELEASE 0.9.19 - MAP MICROFIX
---------------------------

1. ADS-B MAP AND RADAR
---------------------
Before: old aircraft stayed visible after ADS-B stopped; other SBS
messages could keep an outdated position on screen.
Changed: both map views show positions received within 60 seconds from
an active ADS-B scan. A confirmed STOP clears the live aircraft cache.
A pending STOP is reported honestly. Saved XP and logs remain intact.

2. MESH MAP AFTER RESTART
------------------------
Before: startup and GPS backfill could put all saved mesh contacts on
the map, without receiving them in the current session.
Changed: MeshCore and Meshtastic map markers start empty after restart.
A contact appears after reception in this session. GPS backfill alone
does not restore historical markers. Contacts, notes, XP and logs stay
saved. Mesh markers received this session remain until the game closes.

3. CUMULATIVE UPDATE AND NOTES
-----------------------------
Before: the update window always displayed the entire published text.
Changed: 0.9.19 can select versioned sections for missing fixes in future
updates. One confirmation installs all missing code changes together.
Existing 0.9.17 and 0.9.18 readers show both sections during this first
transition. The 0.9.18 section below is for users upgrading from 0.9.17.

RELEASE 0.9.18 - PREVIOUS FIXES
-----------------------------
Catch-up for users upgrading from 0.9.17. Already on 0.9.18? These fixes
are already installed; the new changes are in the 0.9.19 section above.

WatchDogsGo 0.9.18
Original game by LOCOSP. Modified by KiloGramowy.

1. XP, LEVEL AND SAVED DATA
---------------------------
Before: an old v1 save could lose XP, badges, contacts and history.
Changed: preserve saved progress and counters; create a backup before
migration. Saved zero stays zero. Unsafe migration stops startup.
For a separate clone, run.sh accepts the old installation root as its
data argument. Already erased XP requires an intact save or backup.

2. BLE SCAN COMPLETION
----------------------
Before: Linux bridge results could end with a false scan timeout.
Changed: accept its final BLE scan done marker. Keep XIAO/projectZero
Summary support and save/STOP checks. Adapter warnings pause scanning;
late replies cannot restart a cancelled schedule.
Validation: bridge completion handling passes software tests. AC1200
hardware testing is pending; our own setup uses XIAO ESP32-C5.
The fix is expected to address this completion-marker mismatch when
the Linux adapters, drivers and bridge are already working.

3. MESHCORE CONTACT LIST
------------------------
Before: Ctrl+H hid an empty list; keys still reached the chat.
Changed: show CONTACTS (0), block chat input while the panel is open,
and close the empty panel with Esc without leaving chat. Keep the panel
visible after deleting the final contact.

4. MESHTASTIC CONTACT LIST
--------------------------
Before: Ctrl+H hid the panel when no contacts were saved.
Changed: show CONTACTS (0) and the empty-list message. Keep MeshCore and
Meshtastic contacts and panel states separate.

5. UPDATE NOTES
---------------
Before: change descriptions used one text color.
Changed: use numbered yellow titles on dark strips, underlines and blank
line; keep the factual description in white.
