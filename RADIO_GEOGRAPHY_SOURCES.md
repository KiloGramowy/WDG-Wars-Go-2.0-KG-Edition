# Offline RF geography extraction

Built and checked on2026-10-29. Runtime files are only `watchdogs/radio_geography.py`, `watchdogs/radio_countries.json` and `tests/test_radio_geography.py` in `.scratch/integration`. No real GPS, radio, database, device or network is opened by the runtime or tests.

Country geometry is Natural Earth **1:10m**, pinned repository commit`ca96624a56bd078437bca8184e78163e5039ad19` (2022-06-02T07:25:00Z). This is the repository master head obtained on the verification date, not a claim that the world geometry was surveyed in2026. [Source repository](https://github.com/nvkelso/natural-earth-vector/tree/ca96624a56bd078437bca8184e78163e5039ad19), [public-domain terms](https://www.naturalearthdata.com/about/terms-of-use/).

The extraction uses `ne_10m_admin_0_countries_lakes.geojson`; subtracts `ne_10m_admin_0_disputed_areas.geojson` and `ne_10m_admin_0_disputed_areas_scale_rank_minor_islands.geojson`; retains original rings/holes; selects complete original polygon components for the documented scope. A component-selection envelope is a build-time scope filter, never a GPS→country bounding-box classifier. The runtime uses point-in-polygon tests including holes, and returns unknown for exact boundaries or overlapping matches. Source URLs, SHA-256 hashes, date and scope reside in the generated JSON.

Supported countries: ES, GB, DE, FR, PL, NL, BE, PT, IT, CZ, AT, DK, SE, NO, FI, IE, CH and US. ES includes mainland/Balearics, excludes Canaries/Ceuta/Melilla/African possessions. FR is metropolitan including Corsica. NO excludes Svalbard/JanMayen. US includes contiguous48/Alaska/Aleutians/Hawaii and excludes overseas dependencies, including Midway. PT includes Azores/Madeira. Country mapping states documentary Meshtastic EU_868/US region applicability; it does not choose a local RF preset.

Build-only dependency Shapely2.1.2 is installed under `.scratch/auto-gps-20261029/build-deps`; it is not a production requirement. `build_radio_countries.py` simplifies with topology preservation at0.0003degrees (surface displacement <48m including coordinate rounding; the source itself has separate cartographic error). Coordinates are normally5 decimals and remain6 if rounding would break topology. Every output polygon is checked for validity. Output including the additional international lines is2,156,212bytes, below the2,200,000byte build/test limit.

Natural Earth does not accurately resolve every micro-enclave. Broad **10km manual-only policy circles** therefore cover Baarle-Hertog, Büsingen, Llívia and Campione d'Italia. These deliberately exclude surrounding undisputed land too; they are safety policy areas, not representations of the municipal borders. Centers come from Wikidata's CC0 P625 records, retained in `enclave-policy-centres.json` and the generated catalog with immutable revision IDs. Records: [Baarle Q244959](https://www.wikidata.org/wiki/Special:EntityData/Q244959.json?revision=2547787183), [Büsingen Q61698](https://www.wikidata.org/wiki/Special:EntityData/Q61698.json?revision=2550427393), [Llívia Q13745](https://www.wikidata.org/wiki/Special:EntityData/Q13745.json?revision=2549192334), [Campione Q244207](https://www.wikidata.org/wiki/Special:EntityData/Q244207.json?revision=2554953740). These are coordinate-dataset sources for policy centers, not authoritative boundary geometry.

`boundary_distance_km` is approximate local equirectangular distance to polygon edges (country border, **coast**, lakes, holes) and the closest policy-circle edge. It is useful for a caller guard near the boundary, not a legal survey, positional error bound, or RF-coverage estimate. Source generalization may leave actual coastal land unknown: Copenhagen55.6761,12.5683 is a retained example. No city-name, bounding-box or radius fallback fabricates a country for such a point. SanFernando36.4666,-6.1988 resolves ES with distance approximately1.91km; the test guard's final threshold belongs to the state controller.

Country boundaries change, source features may be omitted, and small lakes/coastal structures are not exhaustively represented at1:10m. This is deliberately a finite offline catalog with conservative unknown results, not complete worldwide geocoding.

The source's positional error is not bounded by the48m simplification figure. For example the dataset puts the US/Canada edge near longitude−100 at about48.9926°N, rather than an exact49°N parallel. Application boundary-guard thresholds must account for cartographic source uncertainty separately from simplification and GPS error; a small guard cannot promise survey-accurate country assignment.

## Separate international boundary-line distance

Added the primary [Natural Earth1:10m admin0 boundary lines land snapshot](https://raw.githubusercontent.com/nvkelso/natural-earth-vector/ca96624a56bd078437bca8184e78163e5039ad19/geojson/ne_10m_admin_0_boundary_lines_land.geojson), pinned to the same commit. Original downloaded GeoJSON SHA-256: `74d9c16229c095fde65943a9919e337682f044bcebccb120764f38edf3b70f4a`. The generated JSON records this file URL/hash alongside the existing polygon sources.

Stable source fields `ADM0_A3_L` and `ADM0_A3_R` select72original features adjoining at least one supported country; `ne_id` is retained as `source_id`. The source features include65`Land` and7`Water Indicator` entries. Water-indicator entries represent mapped international boundaries through water, such as the US/Canada boundary; they are not coastlines and remain conservative border guards. Their source classifications do not constitute survey/legal validation.

The generated `land_borders` array contains970open line parts and9410vertices before tiny-line rounding fallback. Country memberships, original A3 sides, source identifier and type accompany each part. Lines are simplified at0.0003degrees independently of the polygons; separate line parts are never joined or automatically closed. No original country polygon, exclusion or manual-only circle was changed. SHA-256 of the compact, key-sorted JSON `areas` value before and after this extension is identical: `6dd312df59562f0b22281ebd44a92ebbfe97816a26c71fe39dafd82885fefe6e`.

`resolve_area()` additionally returns `land_boundary_distance_km`. This is the distance to the selected country's international line layer, **capped at6km**. A value of6means at least6km from the mapped line; it is not a measured or full-distance value. `None` means the separate line dataset is unavailable and must not be interpreted as far from a border. This permits a caller's2km international-border margin separately from its250m polygon/coast margin. These thresholds are conservative application policy, not a proof of cartographic or GPS accuracy. The source's documented~820m US/Canada example remains geometrically unchanged; the larger land-line margin covers that example without excluding SanFernando merely because its coast is~1.91km away.

Performance metadata is built once when the bundled catalog is loaded. Cached32-segment chunks and bounding-box lower bounds accelerate distance calculations without changing coordinates or the scalar projection calculation. The regression tests cover open versus artificially closed lines, country scoping, exact line proximity, missing line metadata, anti-meridian wrapping and unchanged country-geometry hash. All14geography tests passed.
